# ぴったりたたみ（pitta-clothes）

服をドラッグで折りたたんで、収納のサイズに **ぴったり** 合わせるブラウザゲーム。

- **パズル**：12 ステージ。少ない手数で PERFECT を目指す（★評価）
- **タイムアタック**：90 秒で何枚しまえるか

仕様は [SPEC.md](SPEC.md) を参照。

## 遊び方

服をつかんでドラッグすると、つかんだ点と指の中間に折り線ができて、その側が折り返されます。
回転（R）・裏返し（F）は手数に数えません。厚さが収納の高さを超えると入りません。

## 動かす

ビルド不要の静的サイトです（ES Modules を使うのでローカルサーバーが必要）。

```sh
npm start          # python3 -m http.server 8000 → http://localhost:8000/
npm test           # 布モデルとステージ（最短手数）のテスト
```

GitHub Pages にそのまま公開できます。
